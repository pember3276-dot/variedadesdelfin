¿Cómo saco la clave? (solo Daniel, 2 minutos)
  1. Abre este enlace de GitHub con la cuenta dueña de la tienda.
  2. En Repository access elige Only select repositories y marca variedadesdelfin.
  3. En Permissions → Repository permissions → Contents elige Read and write.
  4. En Expiration elige No expiration (o un año).
  5. Toca Generate token, copia la clave (empieza por github_pat_) y pégala arriba.

Esa clave solo puede tocar los archivos de la tienda, nada más de la cuenta. Si se pierde un celular, bórrala en GitHub y saca otra.
